# Counterterrorism Spending and Terrorist Attack Severity

## Research Question

Is higher military/security spending associated with fewer terrorist attacks or lower terrorism fatalities in later years?

## Study Design

This project uses a country-year panel dataset from 2001 to 2020. Terrorism data comes from the Global Terrorism Database. Military spending, GDP, and population data come from the World Bank and SIPRI military expenditure indicators.

## Key Variables

### Dependent Variables

- Terrorist attacks per country-year
- Terrorism deaths per country-year
- Wounded per country-year
- Fatalities per attack

### Independent Variables

- Military expenditure, current US$
- Military expenditure as % of GDP
- Lagged military expenditure

### Controls

- GDP
- Population
- Year fixed effects

## Method

The main model uses lagged military spending to test whether prior-year spending is associated with later terrorism outcomes.

## Important Limitation

Military expenditure is only a proxy for counterterrorism spending. It includes broader defense spending and does not isolate spending specifically used to combat terrorism.

## Expected Outputs

- Processed country-year panel dataset
